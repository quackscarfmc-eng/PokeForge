     1→# Project Worklog — PokeForge (Custom Pokémon Editor for pokeemerald-expansion)
     2→
     3→## Project Overview
     4→
     5→**Goal:** Build a comprehensive Next.js web application ("PokeForge") that lets users add fully custom
     6→Pokémon, moves, types, abilities, items, and status conditions to a `pokeemerald-expansion` ROM-hack
     7→codebase — all from a single GUI, with strong safety guarantees (validation, dry-run plans, lint,
     8→backups, rollback, build checks).
     9→
    10→**Reference project:** https://github.com/Nexxo11/AxoloteDex (Python + dearpygui desktop tool,
    11→species-only editor). We extend the same safe workflow (Validate → Dry-Run → Review → Apply → Build)
    12→to ALL custom-content categories and deliver it as a modern web app.
